KICHUKHON CAFE - QUICK START

1) Install Node.js 20+ and PostgreSQL.
2) Create database: CREATE DATABASE kichukhon_cafe;
3) Open backend folder, copy .env.example to .env, edit DATABASE_URL and JWT_SECRET.
4) In backend terminal:
   npm install
   npm run db:migrate
   npm run db:seed
   npm run dev
5) Open frontend folder, copy .env.example to .env.
6) In frontend terminal:
   npm install
   npm run dev
7) Visit http://localhost:5173
